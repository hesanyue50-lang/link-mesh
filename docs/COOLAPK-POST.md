# 酷安宣传文案

---

**标题（三选一）**

1. 两台设备之间传文件，为什么要先上传到别人的服务器？
2. 没有账号、没有广告、没有云的互传 App：Link Mesh
3. 安卓 4.4 都能跑的局域网直连工具，电脑免装软件也能收发

---

**正文**

先说结论：**Link Mesh 不做任何"云端中转"，因为你的设备之间本来就能直连。**

微信传文件要压缩、要登录；网盘要先上传再下载，一个文件走两遍流量，还在别人服务器上过夜；快传类 App 不是塞广告就是要你注册。其实两台设备在同一个 Wi-Fi 下，文件直接从一台飞到另一台就行。

**Link Mesh 做了什么：**

🔹 **局域网直连**
打开 App 自动发现对方，无需配对码。传文件带断点续传 + SHA-256 校验，1GB 文件内存占用恒定，切后台回来接着传。老手机（Android 4.4）也能装。

🔹 **网页端（电脑不用装任何东西）**
手机上点一下，电脑浏览器打开一个地址，就是一个完整的聊天页面：发文本、传文件（带进度条）、下载文件。访客各自独立，不会和 App 内的聊天混在一起。右上角还有「下载 App」——发给没装的朋友，装完就能用。

🔹 **P2P 跨网直连（Android 5.0+）**
不在一个网络时，用二维码信令建立 WebRTC 直连。只用公共 STUN，不租 TURN 服务器（零成本）。打洞失败 60 秒内明确告诉你，不会让你干等。

🔹 **一些在意的细节**
- 深色/浅色/跟随系统，切换有过渡动画
- 底部导航可以拖拽排序、隐藏、设默认主页
- 接收文件存到你选的公共文件夹，文件管理器直接看
- 自动接收可关——关掉后每个文件都要你点头
- 无广告、无遥测、只申请必要权限（网络/存储/通知）

**架构上就没有"上传"这条路**：所有传输都是设备到设备，代码开源（AGPL-3.0），可以自己查证。
